Led a 4-person team building a composite index scoring 215 NYC neighborhoods on transit equity (income, car dependency, subway access, bus reliability, ridership). Built an interactive Leaflet.js map with adjustable weights, deployed on Netlify. Presented at the NYC School of Data Conference.
`Python` `pandas` `Leaflet.js` `HTML/CSS`

`Python` `OpenAI API` `LangGraph` `Streamlit`
